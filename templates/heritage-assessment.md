## Part 4: Mitigation Options

### Option A: Preserve Existing Profile (Minimal Heritage Harm)

**Description:** [Method that keeps the exterior appearance unchanged]  
**Heritage impact:** MINIMAL  
**Technical feasibility:** [Is it possible given building physics, code requirements?]  
**Cost premium:** [vs. standard approach]  
**Byantikvaren approval:** LIKELY  

**Example for roof insulation:**
- Interior insulation only (add 300 mm mineral wool inside, below existing roof rafters)
- Keeps steep gable profile
- Challenges: Interior ceiling height lost (0.3 m); moisture risk if not carefully ventilated
- Cost: +2k NOK (bespoke vapor barrier, ventilation detail)

---

### Option B: Sympathetic Modern Design (Moderate Heritage Impact)

**Description:** [Method that changes appearance but in a historically-informed way]  
**Heritage impact:** MODERATE  
**Technical feasibility:** [Is it compatible with structural/energy requirements?]  
**Cost premium:** [vs. standard approach]  
**Byantikvaren approval:** UNCERTAIN (depends on quality of design)  

**Example for roof insulation:**
- New flat roof with sympathetic parapet (design echoes era: arched copper coping, recessed edge, matching materials/color)
- Triple-glazed replica windows in aluminum (designed to match 1895 proportions + profile)
- Energy performance: Full upgrade (U ≤ 0.18)
- Heritage effect: New, but contextually respectful (not jarring)
- Cost: +5–8k NOK (bespoke design, premium materials)

---

### Option C: Formal TEK17 Exemption (Accept Heritage/Energy Trade-off)

**Description:** [Request exemption from energy code under TEK17 §15-1(5)]  
**Heritage impact:** NONE (existing building preserved as-is)  
**Code compliance:** NON-COMPLIANT with energy standard (exemption granted)  
**Technical feasibility:** N/A (no work)  
**Cost:** 0 (bureaucratic, no construction)  
**Byantikvaren approval:** LIKELY  

**Example:**
- Keep existing roof + windows unchanged (preserve heritage)
- Energy performance unchanged (U ≈ 0.9 W/m² for windows)
- Apply for exemption: Document heritage significance → Byantikvaren agrees modification is "unreasonable" → Energy code waived
- Owner accepts higher heating costs (long-term operating cost)

### Option D: Phased Approach (Defer Some Work)

**Description:** [Prioritize work that has LESS heritage impact now; revisit other elements in future]  
**Heritage impact:** VARIABLE (lower now, potential later)  
**Timeline:** Initial work in Year 1; deferred work in Year 5–10

**Byantikvaren approval:** LIKELY (shows respect for heritage through deliberate sequencing)  

**Example:**
- Year 1: Upgrade roof (justify by building code requirement; design sympathetically)
- Year 5: Reassess windows (future heritage assessment may reveal different priority)
- Year 10: Consider energy efficiency of heating system (potentially non-visible work)

## Part 5: Byantikvaren Consultation & Approval Pathway

### Pre-Application Meeting (Forhåndskonferanse) Preparation

**Objective:** Get informal guidance on which mitigation option Byantikvaren prefers.

**Materials to bring:**
- [ ] Project photos (exterior elevations, key interior spaces)
- [ ] SEFRAK registry printout
- [ ] Proposed design sketches (all mitigation options)
- [ ] Material samples (if visible changes proposed)
- [ ] TEK17 / energy requirement justification (if work is motivated by code compliance)

**Key questions to ask:**
1. "Which of these mitigation options best preserves the heritage value?"
2. "Are there precedents for similar buildings that you've approved?"
3. "What are the deal-breaker issues that would force you to object?"
4. "If we proceed with Option [X], what documentation/conditions do you require?"

**Expected outcome:** Informal approval of one mitigation strategy (e.g., "Interior insulation is fine; please avoid the parapet design")

---

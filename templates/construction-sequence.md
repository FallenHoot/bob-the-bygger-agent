## Critical Path Analysis

**Longest sequence (determines project duration):**

```
Foundation cure (7 days)
  ↓ (depends on)
Structural frame assembly (2–3 weeks)
  ↓ (depends on)
Roof sheathing + weather-tight (1–2 weeks)
  ↓ (depends on)
Interior rough-ins can start in parallel (2–3 weeks)
  ↓ (depends on)
Drywall + finishing (3–4 weeks)
  ↓ (depends on)
Final inspections + cleanup (1 week)

**Total critical path: ~13–18 weeks (3–4.5 months)**
```

**Parallel opportunities (reduce schedule):**
- Rough-in trades can run in parallel if weather-tight achieved
- Painting can start before all trades finish (plastic dust barriers)
- Exterior work (site grading, landscaping) can run parallel to interior finishing

## Weather & Seasonal Constraints

**Outdoor/exposed work (sensitive to weather):**
- [ ] Foundation: avoid frost risk (spring: cover forms in April; fall: monitor temps after Sept)
- [ ] Roofing: dry conditions required (shingles + underlayment)
- [ ] Exterior painting: avoid rain, temps < 5°C or > 30°C
- [ ] Window installation: protect from rain during flashing work

**Seasonal advantages:**
- **Summer:** Best for roofing, exterior work (long days, dry)
- **Spring/Fall:** Moderate temps (avoid extreme cold/heat)
- **Winter:** Interior work only (heating/drying delays; frost risk on concrete)

**Contingency:** Add 2–4 weeks buffer for weather delays (especially Nordic climates with winter precipitation)

## Notes & Contingencies

**Assumptions:**
- Permit approved before Phase 1 start
- All materials on-site 1 week before needed
- Weather cooperates (minimal rain/frost delays)
- No undiscovered structural issues during demolition

**What could delay the schedule?**
- Material delivery (window, HVAC): +2–4 weeks
- Inspector defect findings: +1–2 weeks remediation
- Weather (rain, frost, extreme temps): +2–4 weeks
- Change orders during construction: variable

**Mitigation:**
- Order long-lead items immediately (8 weeks before scheduled use)
- Hold weekly coordination meetings (catch conflicts early)
- Plan contingency: add 20% buffer to schedule
